# Castello Forte — Sistema de Recepção

Sistema web para gestão operacional da recepção da **Castello Forte Barbearia**, contemplando régua de cobrança, resgate de clientes inativos, vendas de produtos e gestão de assinaturas.

## 🏛️ Identidade Visual & Manual de Marca

- **Tipografia:**
  - Primária (Títulos e Destaques): `Cinzel` (Google Fonts)
  - Corpo & Interface: `Montserrat` (Google Fonts)
  - Numérica & Dados Técnicos: `IBM Plex Mono`
- **Paleta de Cores Institucional:**
  - **Ouro Envelhecido / Latão:** `#C9972B` (Light: `#E5C56A`, Dim: `#8C6415`)
  - **Bordô Imperial:** `#5A0F16`
  - **Marfim / Pergaminho:** `#F1E7D2`
  - **Fundo Escuro:** `#050505` / Superfícies `#0E0D0B`, `#161412`

## 🚀 Funcionalidades

- **Régua de Cobrança:** Controle de débitos, envio de mensagens e acompanhamento de status.
- **Resgate de Clientes:** Identificação de clientes sem retorno e disparo de abordagens personalizadas.
- **Vendas & Produtos:** Controle de vendas de produtos e serviços na recepção.
- **Assinaturas:** Gestão de planos e membros do clube da barbearia.
- **API Serverless:** Integração com Vercel KV para persistência e sincronização de dados.

## 🛠️ Tecnologias

- HTML5 / Vanilla CSS3 / JavaScript Moderno
- Google Fonts (`Cinzel`, `Montserrat`, `IBM Plex Mono`)
- Vercel Serverless Functions (`@vercel/kv`)
